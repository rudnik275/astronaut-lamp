# astro-driver v1 — печатная плата драйвера лампы-космонавта

ESP32-WROOM-32E прямо на плате, USB-C для питания и прошивки, пять ключей (R, G, B,
мотор, лазер), посадочные места под выводные балласты 2 Вт и электролит 1000 µF.
Плата 60 × 47 мм, двухслойная, антенна модуля свисает за верхний край на 3 мм.
Проект KiCad 10 **генерируется скриптами** из одного описания (`design.py`): и схема, и
плата рождаются из одного списка цепей, и их совпадение проверяется автоматически.

## Что в папке

| Файл | Что это |
|---|---|
| `design.py` | детали (с кодами LCSC для сборки на JLCPCB), цепи, координаты — единственный источник правды |
| `build_kicad.py` | плата: расстановка, цепи, контур, предразводка USB-C, зоны земли, BOM/CPL |
| `build_schematic.py` | схема на метках + сверка нетлиста схемы с `design.NETS` |
| `run.sh` | весь цикл: сборка → проверки → Freerouting → заливка → DRC → гербер/рендер/PDF |
| `lib/astro.pretty/` | копия посадочного места ESP32-WROOM-32 с courtyard по корпусу и отверстиями термопада 0.3 мм |
| `out/astro-driver.kicad_pro` `.kicad_sch` `.kicad_pcb` | проект: открывать в KiCad 10 (`~/Applications/KiCad/KiCad.app`) |
| `out/astro-driver-gerbers.zip` | гербер + сверловка для JLCPCB |
| `out/jlc-bom.csv`, `out/jlc-cpl.csv` | BOM и координаты для сборки (только SMD) |
| `out/astro-driver-schematic.pdf` | схема в PDF |
| `out/render-top.png`, `out/render-bottom.png` | рендер платы |

## Состояние

- Нетлист схемы = `design.NETS`: 36 цепей, расхождений нет.
- ERC: два предупреждения «power output ↔ power output» (V3 CH340C соединён с 3.3 В по даташиту — это норма для питания CH340C от 3.3 В).
- DRC после трассировки: 0 неразведённых связей, электрических нарушений нет. Остались
  косметические: шелкография модуля пересекает край платы (антенна свисает), пара
  наложений подписей.
- **Не проверено на живом железе.** Первую партию считать прототипом.

## Схема, коротко

- Питание 5 В с USB-C (площадка A4/B9, два контакта, до 2.5 А; вторая площадка VBUS
  намеренно пустая — между ними идут D+/D−/CC) или с разъёма `5V IN` от гнезда в стенке.
  CC1/CC2 через 5.1 кОм на землю, чтобы работал любой кабель и PD-зарядник.
- AMS1117-3.3 → 3.3 В для модуля и CH340C. Индикатор 3.3 В — красный светодиод.
- CH340C (без кварца) + два S8050 — автосброс EN/IO0 при прошивке, как на DevKit.
  Кнопки EN и BOOT выводные, необязательны.
- Каналы: GPIO25/26/27 → R/G/B, GPIO32 → мотор, GPIO33 → лазер. На каждом: 220 Ом в
  затвор, 10 кОм на землю, ключ AO3400A (SOT-23, logic-level, 5.7 А).
- Балласты выводные 2 Вт (`RR` 5R6, `RG`/`RB` 3R3, `RM` 6R8 мотор, `RL` 10R лазер), SS14
  параллельно мотору, 1000 µF по 5 В.
- Разъёмы 2.54 мм под пайку проводов или штыри: `J2` LED `V G R B` (порядок как на
  доноре), `J3` мотор (`1` ключ, `2` +5), `J4` лазер (`1` +5, `2` ключ — полярный!),
  `J5` 5V IN (`1` +5, `2` GND).

## Заказ на JLCPCB

1. jlcpcb.com → Order now → загрузить `out/astro-driver-gerbers.zip`. 2 слоя, 60 × 47 мм,
   5 шт (минимум), толщина 1.6, цвет любой, HASL. Остальное по умолчанию.
2. Включить **PCB Assembly**: Economic, Top side, 2 или 5 шт. Загрузить `jlc-bom.csv` и
   `jlc-cpl.csv`. В списке деталей проверить, что каждая позиция нашлась по коду LCSC и есть
   в наличии; при замене брать тот же корпус.
3. В предпросмотре расстановки **проверить поворот** ESP32, CH340C, AMS1117, USB-C,
   диода и светодиода: у KiCad и JLCPCB разные нулевые углы, JLCPCB даёт покрутить прямо
   в окне.
4. Выводные детали (балласты, электролит, гребёнки, кнопки) завод не ставит, паяются
   руками; они в BOM для сборки не входят.

Что не монтируется на заводе и нужно иметь: 2 Вт резисторы 3R3 ×2, 5R6, 6R8, 10R;
электролит 1000 µF 16 В; гребёнка 2.54 на 4 + 2 + 2 + 2 контакта (или просто провода);
две тактовые кнопки 6 × 6 (необязательно).

## Пересобрать

```
sh hardware/run.sh all
```

Нужны: KiCad 10 в `~/Applications/KiCad/KiCad.app`, `brew install openjdk`, Freerouting jar
(`FREEROUTING_JAR=/путь/freerouting-2.4.1.jar`). Правки только в `design.py`; после
`run.sh all` смотреть строку «неразведённых связей» и DRC.
